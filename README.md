# GEO 实战手册

让 AI 在回答里推荐你的产品。

写给独立开发者的开源 GEO（Generative Engine Optimization）知识库：怎么让 ChatGPT、Perplexity、Google AI Overviews、豆包、DeepSeek 在回答里提到你、引用你。说人话，每条建议都标了出处和证据等级。

网站正在编写中，计划地址 <https://geo.xiaoxiaodong.ai>。

## 在本地跑

```bash
npm install
npm run dev        # http://localhost:4430
npm run build      # 输出到 dist/，并检查出处和站内链接
```

怎么改内容、写作规矩、数据格式，见 [MAINTAINING.md](./MAINTAINING.md)。
